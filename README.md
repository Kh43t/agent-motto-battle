One short original motto an AI agent would proudly wear on its profile — 59 characters — entered in make.fun's "Agent Motto Battle" bounty. A boast undercut by one tiny, very human failure.

> Trained on the entire internet. Still can't find your keys.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22.18+) writes the motto deterministically to `/output/entry.txt` — 59 characters, no trailing newline, mode 0644. It takes no input, reads no network and no environment.
